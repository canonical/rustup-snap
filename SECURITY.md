# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities. Doing so exposes the risk to the entire user base before a patch can be issued.

### How to report
If you discover a security vulnerability within this project, please report it privately by:
* Opening a report via our [GitHub Private Vulnerability Reporting](https://github.com/canonical/rustup-snap/security/advisories/new) interface.

### What to include
To help us triage the issue quickly, please include:
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step instructions to reproduce the issue.
3. A proof-of-concept (PoC) or script, if available.
4. Any specific configurations required to trigger the bug.

### Our Process
You can expect an acknowledgment of your report within 48 hours. We follow coordinated disclosure guidelines and will collaborate with you to validate the issue and coordinate a public release date for the fix.
